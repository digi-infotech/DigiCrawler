# DigiCrawler (site-contact-scraper)

Upload an Excel list of business websites and get back the same list with the **business name, emails and phone numbers** found on each site.

**Quick start:** install Docker Desktop, double-click `start.bat` and open http://localhost:3003.

For step-by-step instructions for managers and developers, see **[ONBOARDING.md](ONBOARDING.md)**.
